# 本地商品演示数据

本批次新增 20 条商品及 20 条 SKU：服饰 6 条、数码 6 条、家居 8 条。修复原商品 100、102、105 的主图、相册、SKU 图片以及详情内的随机图库图片。现有商品名称、价格、库存、编号和历史订单快照保留。

`manifest.json` 记录商品中文名称、来源标题、来源页面、原始图片地址以及本地文件的一一对应关系。新增商品图来自 DummyJSON 的商品数据；原有白色 T 恤、黑色耳机、黑色保温杯使用对应物品的展示素材。图片用于本地教学演示，不作为材质、品牌授权、续航或实际库存的证明。

## 使用

在项目根目录运行：

```powershell
node scripts/seed-catalog.cjs
node scripts/seed-catalog.cjs --apply
```

第一条仅准备 SQL；第二条备份当前商品及 SKU 表、复制图片并在事务内写入本地数据库。使用现有 `.runtime/mysql-client.ini`，不会输出数据库密码。新增数据按 `DEMO-20260912-*` 商品编码去重，重复运行不重复新增，也不重置已兑换的库存。请单次运行，避免并发导入。

图片源文件随本目录保留，运行时复制到 `.runtime/uploads/catalog-20260912/`，由后端 `/profile/` 静态资源服务提供。默认图片地址为 `http://127.0.0.1:8080`；若迁移到其他服务地址，首次导入前设置 `CATALOG_IMAGE_ORIGIN`。已存在的新增数据不会被脚本覆盖，迁移已有数据应单独更新图片地址。

备份位于 `.runtime/catalog/before-*.sql`；执行 SQL 位于 `.runtime/catalog/seed.sql`。历史订单快照不更新，避免改变订单购买时的信息。
